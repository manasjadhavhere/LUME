# LUME Documentation & Assets

This directory contains platform design assets, design reviews, and prototypes for LUME:

- **[Master Platform Documentation](../README.md)**: Full architecture specifications, environment variable reference, setup guides, and deployment instructions.
- **`Lume_PRD.pdf` / `Lume_PRD.docx`**: Original Product Requirements Document.
- **`prototypes/`**: HTML email previews (`booking-email-preview.html`) and initial interaction prototypes (`lume-app.html`).
- **`ui-ux-review/`**: Complete UI/UX design audit, visual guidelines, and interactive review suite (`index.html`).
